## What's the problem

So, the problem is that the old website is not easy to maintain, I can list as those 4.

1. If I update a header, I need to update all the page at same time, which is not easy to maintain.
2. it is not easy to maintain CSS, esp. when they are cross over.
3. I cannot control the new website very well, because I need to copy and psate layouts for everything.
4. Convert Markdown to HTML is feel too low.

Until I discovered [Astro](https://astro.build), a new framework that is very easy to use. and it solve all the problem I have, and I can use it to build a new website.

esp. they are very fast and good for SEO!
